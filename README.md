# TetrisGame-4TL
# 🧱 Survival Tetris Game - Nhóm 4TL - Đồ án cuối kỳ môn học KNNN (SS004.Q27)

Một phiên bản Tetris kinh điển được lập trình bằng C++ và chạy trên môi trường Windows Console. Đây là đồ án môn học nhằm rèn luyện tư duy thuật toán, cấu trúc dữ liệu và thực hành quy trình phối hợp quản lý mã nguồn qua Git.

## 👨‍💻 Đội ngũ phát triển (Team 4TL)

Dự án là thành quả làm việc tích cực và phối hợp nhịp nhàng của tập thể nhóm 4TL. Thay vì làm việc độc lập, đồ án được chia nhỏ thành nhiều module (xử lý giao diện, thuật toán xoay, vòng lặp game, quét mảng...) để tất cả các thành viên cùng đóng góp và ráp nối thành một trò chơi hoàn chỉnh.
